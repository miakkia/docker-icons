# Docker Icons

Public icon repository for Docker and Unraid container templates.

## Structure

Icons are stored under `icons/` and should use stable, lowercase filenames.

Current naming convention:

- `icons/mediaops-logo.png`
- `icons/adguard-home.png`
- `icons/dozzle.png`
- `icons/uptime-kuma.png`
- `icons/ombi-discord-router.png`

These files are intended to be referenced through `raw.githubusercontent.com` so Unraid can download and cache them without authentication.
